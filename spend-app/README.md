# 每日消费 · 手机安装版

一个可以装到手机主屏幕的记账应用（PWA）：独立窗口、自带图标、离线可用，账目数据只保存在手机浏览器里，不会上传。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用本体（也可以直接双击打开使用） |
| `manifest.json` | 应用名称、图标、启动方式 |
| `sw.js` | 离线缓存，装好后断网也能记账 |
| `icons/` | 桌面图标（普通 + 自适应） |
| `start-server.bat` | 在电脑上临时起一个局域网服务，方便手机安装 |
| `serve.py` | 本地服务脚本（修正 `.js` 的 MIME，浏览器才能注册离线缓存） |

## 方式一：现在就在手机上装（局域网）

1. 双击 `start-server.bat`，保持黑色窗口开着（首次可能弹出防火墙提示，勾选「专用网络」并允许）。
2. 手机连上**同一个 Wi-Fi**，用浏览器打开窗口里显示的地址，例如 `http://192.168.1.5:8765/`。
3. 安装：
   - **iPhone（Safari）**：点底部「分享」→「添加到主屏幕」→ 添加。
   - **安卓（Chrome/Edge）**：菜单 →「添加到主屏幕」/「安装应用」。

> 这种方式适合先试用：电脑上的服务要一直开着，手机才能打开。安卓在 `http://` 地址下一般只能添加“快捷方式”，不是完整的独立应用。

## 方式二：传到免费静态托管（推荐，真正装上、随时随地用）

手机浏览器只允许从 **https** 地址“安装” PWA，所以把整个 `spend-app` 文件夹原样传到一个静态托管上就行。托管只放程序文件，**账目数据仍然只存在你手机里**。

以 GitHub Pages 为例（免费）：

1. 登录 github.com，新建一个仓库（Public，名字随意）。
2. 进入仓库 →「Add file」→「Upload files」，把 `spend-app` 里的所有文件和 `icons` 文件夹拖进去，提交。
3. 仓库「Settings」→「Pages」→ Source 选「Deploy from a branch」→ 分支 `main`、目录 `/ (root)` → Save。
4. 等 1～2 分钟，访问 `https://你的用户名.github.io/仓库名/`。
5. 手机打开这个 https 地址：
   - 安卓 Chrome：会提示「安装应用」，或菜单里选「安装应用」。
   - iPhone Safari：「分享」→「添加到主屏幕」。

装好后从桌面图标直接打开，全屏无地址栏；断网也能记账，数据在手机本地。

也可以把文件夹直接拖到 Netlify Drop（`app.netlify.com/drop`）得到 https 地址，步骤类似。

## 数据与备份

- 数据保存在浏览器的 localStorage，不上传服务器。
- 换手机、清理浏览器数据前：应用内右上角「设置」→「备份 JSON」，之后在新设备「导入 JSON」。
- 「导出 CSV」可以用 Excel 打开。

## 更新应用

改完 `index.html` 后，把 `sw.js` 第一行的缓存版本号改一下（例如 `daily-spend-v1` → `daily-spend-v2`），手机重新打开一两次就会更新。
